AARRR (pirate metrics), the North Star Framework, Input and Output Metrics and growth loops each answer a different growth question. This guide shows which one to reach for, and how the four fit together into one system for planning growth.

In short

AARRR shows where users leave, the North Star Metric names the one number that reflects the value they get, input metrics turn that number into levers each team owns, and growth loops make the gains compound. Use the one that matches the question in front of you, and run all four in that order when you plan growth for the year.

Four frameworks, four jobs

What each one works on, and the typical time a first version takes

These four are less alternatives than parts of one growth system. Teams usually pick one at a time, by the problem in front of them, and many come to use all four.

Diagnose

AARRR

Splits the customer lifecycle into five stages, each with a metric, and shows where in the journey people drop out. Dave McClure’s 2007 order is Acquisition, Activation, Retention, Referral, Revenue; many later write-ups put Revenue before Referral.

Typical time for a first funnel review: 2–4 hours

Focus

North Star Framework

Picks the single metric that best captures the core value customers get, and pairs it with 3–5 input metrics that teams can influence directly.

Typical time to agree on the metric: 1–2 days

Operationalize

Input and Output Metrics

Breaks an output, such as the North Star Metric, into input metrics a team can move directly, and pairs any input that can be gamed with a counter-metric.

Typical time for a metric tree: 2–4 hours per team

Compound

Growth Loops

Designs growth as a closed cycle in which each turn’s output, such as shared clips or reinvested revenue, brings in the next users, instead of a funnel that ends at its last stage.

Typical time to map and design a loop: 1–2 days

These typical times are rough guides to a first working version, not fixed costs.

One sentence from each

For Larkwell, a fictional piano-learning app (all figures illustrative), the four frameworks produce four different statements:

  • AARRR: “Our biggest leak is retention: 45% activate, but only 9% are active on day 30.”
  • North Star Framework: “We rally around Weekly Active Learners (3+ lessons a week).”
  • Input and Output Metrics: “The content team grows quality-reviewed beginner lessons from 120 to 128, guarded by the completion rate of new lessons.”
  • Growth loops: “A learner who plays a first song shares a clip that brings in new learners.”

Four terms the growth frameworks share

The frameworks use the same words, and mixing them up is a common source of confused metric discussions. This guide uses them as follows.

Input metric
A controllable, customer-facing metric a team can move directly, such as lesson completion rate or practice sessions per learner. It is a metric, never a task or a project.
Output metric
A result the business wants but cannot move directly, such as retention or revenue. It lags the inputs that drive it and moves when they move.
North Star Metric
The single metric that best captures the core value customers get, chosen as the output the company steers by. It lags its own inputs but leads revenue: when it rises, revenue tends to follow.
Counter-metric
A guardrail that gets worse when an input is pushed too far, so a team cannot hit its number by harming something else. For example, the completion rate of new lessons beside the number of quality-reviewed lessons available.

Start from the question you are facing

Follow the path until it names a framework

To plan growth as a whole, work through the questions in order: they follow the growth system, and the first no names the framework to start with. If you already face one specific question, such as how to keep growing when the ad budget is cut, go straight to the question that matches it.

  1. Can you say why you are not growing, and at which stage of the user journey people leave?

    • NoUse AARRR. Map the five stages, measure the conversion between each, and find the biggest drop-off.
    • YesGo to question 2

  2. Does the whole team agree on the one metric everyone should focus on?

    • NoUse the North Star Framework. Choose the metric that best captures the value customers get.
    • YesGo to question 3

  3. Does each team know what it should do to move that metric?

    • NoUse Input and Output Metrics. Break the metric into inputs each team controls, and pair any input that can be gamed with a counter-metric.
    • YesGo to question 4

  4. Can you grow without spending more on acquisition each cycle?

    • NoDesign a growth loop. Build a cycle in which each turn’s output brings in the next users.
    • YesThe system is in place. Review the funnel each quarter with AARRR to find the next leak.

Five situations and the framework for each

Find the one closest to yours

  • “Subscribers cancel after their first month and nobody knows why.”

    AARRR: a funnel analysis shows which stage of the user journey is broken before anyone starts fixing things.

  • In a PM interview: “How would you measure success for this product?”

    North Star Framework with Input and Output Metrics: interviewers want to see you pick one metric and break it down into the inputs that drive it.

  • “Growth depends entirely on paid ads, and the budget is being cut.”

    Growth loops: design organic growth that reinforces itself, such as a viral or content loop.

  • “Teams are working hard, but the metrics aren’t moving.”

    North Star Framework with Input and Output Metrics: each team needs a clear lever tied to the one metric that matters.

  • “We’re building the growth team’s annual plan.”

    All four, in sequence: the plan needs the full picture of diagnosis, focus, execution and compounding. See how they fit together.

One growth system in four steps

Each framework answers the question the one before it raises

For an annual plan, run the four in order. The worked example follows the same company as the AARRR, North Star Framework, Input and Output Metrics and Growth Loops guides through each step.

Worked example

Larkwell’s growth plan, one framework at a time

Larkwell, a fictional piano-learning app, gets 80,000 new accounts a month. All figures are illustrative.

  1. Diagnose with AARRR

    The biggest leak is retention. 45% of new accounts complete a first song lesson within 24 hours, but only 9% are still active on day 30. Of the learners who activate, four in five (80%) are gone within a month, most of them in the first week. Activation is the second-largest loss by rate: 55% of new accounts never complete a first lesson.

    Fix activation and retention before you spend more on acquisition.

  2. Focus with a North Star Metric

    Larkwell’s North Star Metric (NSM) is Weekly Active Learners: learners who complete at least 3 lessons in a calendar week. It stands at 40,000.

    The metric targets the leak. Three or more lessons a week means a learner is getting value and building a habit, so it rises as retention improves and predicts renewal.

  3. Operationalize with input metrics

    The NSM breaks into input metrics that drive it. Each one has a single owning team and a counter-metric beside it.

    Larkwell’s input metrics, owners and counter-metrics

    The growth team’s lifecycle work also tracks a team-level input, the day-3 reminder return rate, guarded by the notification opt-out rate. Retention sits between all these inputs and the NSM as an intermediate output: no team owns it, and it improves when the inputs do.

    The content team has promised to publish 8 new beginner song lessons this quarter. That is a deliverable; the input metric it moves is quality-reviewed beginner lessons available, from 120 to 128. If the new lessons are weak, their completion rate shows it.

  4. Compound with a growth loop

    Larkwell relies on its paid loop today, which pays back at an LTV:CAC of about 3.2:1. The first-song clip, a viral loop, is the largest untested opportunity and the loop to design once retention improves: a learner plays a first song, the app offers to share a 15-second clip, friends see it and some install, and they reach their own first song and share in turn. Only about 3% of activated learners share a clip today, so the share step is where the loop is weakest.

    Each new learner from the loop enters the funnel, so next quarter’s AARRR review measures the loop too.

How the four steps connect

The leak, retention, picks a North Star Metric that rewards a weekly habit. The inputs give each team a lever on that metric, with a guardrail against gaming it. The clip loop turns the first-song moment into new learners, who enter the same funnel the next review measures.

The system in one interview answer

For a broad growth question in a PM interview, showing the whole system in one answer is more convincing than naming a single framework.

Saying it in an interview

I’d start by mapping the AARRR funnel to find the biggest drop-off.
Then I’d define a North Star Metric that captures the core value users get each week,
break it into input metrics that each team owns, with counter-metrics on any that can be gamed,
and design a growth loop so the product grows on its own momentum.
