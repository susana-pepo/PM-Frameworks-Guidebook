# Design Context — PM Frameworks Guidebook

## Users
Product managers (and PM candidates) learning, revisiting, or interview-prepping
on 24 product frameworks + 6 comparison guides. They read in focused study
sessions — at a desk or on the sofa with a laptop — wanting to *understand and
apply* a framework, not skim marketing copy. Mixed expertise: some meeting a
framework for the first time, some refreshing before they use it at work or in
an interview. The job to be done: "teach me this framework well enough that I can
use it today," plus quick side-by-side comparison when choosing between tools.

## Brand Personality
Three words: **calm, authoritative, characterful** — a well-made reference manual,
not a sticker sheet. The voice is a knowledgeable colleague explaining clearly:
confident, concrete, lightly warm. It should feel like a *paid product* you trust,
evoking focus and quiet confidence rather than hype.

## Aesthetic Direction
"**Field Guide**" editorial direction, refined-editorial execution — the look of a
printed reference binder rendered in warm ink on paper.
- **Type:** Bricolage Grotesque (characterful display) + Hanken Grotesk (warm,
  legible long-reading text) + JetBrains Mono reserved for genuine data (scores,
  codes, keyboard hints). Sentence case. Clear, contrasty hierarchy.
  - **Scale is `rem`-based** (modular ~1.2 ratio, root 16px) so reader zoom /
    browser font-size scales the whole guide. Reading tiers: card / secondary
    body **16px / 1.6**, focal flowing prose **18px / 1.7** (`--leading-reading`),
    sub-heads 22 → 26, section titles 32. Headings hand their sizing to this
    scale — the content normalizer **strips inline `font-size` from h1–h6**
    (outside fixed diagrams) so no source file undercuts the hierarchy. Data
    tables and score values use `tabular-nums`. Diagram type stays literal px.
- **Colour:** warm OKLCH ink-on-paper. Neutrals tinted toward warm paper (~hue 83).
  Never pure #000/#fff. Each of the 6 categories is a calm "index colour" used as
  a rare accent (~10%) + a near-paper page wash; not a drenched rainbow.
- **Surfaces:** hairline borders by default (1px warm gray), soft layered shadows
  (real blur, low opacity), subtle grain texture. No hard offset blocks, no thick
  black brutalist borders, **no left/right accent side-stripes**.
- **Theme:** light by default ("ink on paper") with a faithful dark mode
  ("field guide at night") — both first-class, derived from the focused-study
  reading context. Highlighted/score cells deliberately stay light in dark mode so
  they pop with readable dark text.
- **Reading model:** framework + comparison pages are rebuilt at runtime into a
  fixed-stage horizontal **section deck** (one section per view, rail + arrows +
  dots + swipe + ←/→ keys); panels scroll internally. One idea per view.

### Anti-references
The original source files' neo-brutalist sticker-sheet look: thick black borders,
hard 5px offset shadows, Lilita One, drenched pastel fills, **tiny 10–13px body
type**, and decorative side-stripes. The SPA exists to neutralise exactly that.

## Design Principles
1. **Readability is the product.** Body anchored at 16px, focal reading prose at
   18px (never below); comfortable line-height and a capped measure (~66–70ch).
   E-learning lives or dies on legible, well-chunked text.
2. **Calm over loud.** Hairlines + soft shadows + one rare category accent. Colour
   and emphasis earn their place; they are not the default state.
3. **One coherent product.** The 30 source HTML files are elevated *centrally*
   (tokens, a content normalizer, and framework-page.css) so every framework reads
   as the same designed object — no per-file divergence.
4. **Never distort the teaching.** Diagrams (maps, matrices, curves, plots) are
   hand-placed by pixel — leave their type and layout exactly as authored; only
   lift flowing prose.
5. **No AI-slop tells.** No gradient text, no side-stripe borders, no glassmorphism,
   no cyan-on-dark. If it reads as "which AI made this," it's wrong.

## Where the elevation lives (implementation map)
- `src/styles/tokens.css` — remaps the legacy palette (`--cream`, `--border`,
  `--yellow`, `--shadow-*`, …) onto the refined system; light + dark.
- `src/utils/style-injector.js` — `normalizeContent()` lifts tiny inline font
  sizes to a legible floor and strips banned side-stripes (skipping fixed-layout
  diagrams); `liftFontSizesInText()` also runs on extracted CSS-block sizes and
  JS-generated markup. `extractAndCleanCSS()` strips globals, fonts, and stripes.
- `src/pages/framework.js` / `compare.js` — load source HTML, inject cleaned CSS,
  clean fonts, `normalizeContent()`, run scripts, then `buildReadingDocument()`.
- `src/styles/framework-page.css` — the editorial type scale + reskin for the
  recurring content components (`.c-card`, `.insight`, `.tip`, `.when-card`,
  `.factor-card`, `.qo/.quiz-opt`, inputs) and the section-deck chrome.
